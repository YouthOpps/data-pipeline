# CERN Summer Studentship

The parser reads CERN's public Summer Studentship inventory and the two official opportunity pages it references. The native reference gives the programme and year. CERN repeats a single reference in several disciplines and has reused older URL slugs for newer cycles. Duplicate cards with identical facts collapse to one record. Missing or conflicting cards, mismatched programme and detail identities and ambiguous deadlines stop validation. [Official Summer Studentship programme](https://careers.cern/programmes/summer-studentship/)

CERN's public detail text supplies the Geneva deadline, expected start date and published allowance. The general call's title confirms coverage of both member and non-member states. Both archived cards use the same opaque membership filter despite the general title. The parser represents any confirmed eligibility in human-readable facts and leaves the structured citizenship list unspecified. [General 2027 call](https://careers.cern/jobs/cern-summer-student-programme-2026-member-and-non-member-state/) · [2027 openlab call](https://careers.cern/jobs/cern-openlab-summer-student-programme-2026/) · [CERN openlab FAQ](https://openlab.cern/faqs-summer-student-programme/)

The initial research run captured robots and the official programme with two complete HTTP 200 responses and an acknowledged state receipt. A separate reviewed GitHub Actions successor is required to capture the exact two current detail pages while preserving that state. The parser currently has a real inventory fixture and synthetic detail tests. The detail capture, adaptation to the exact HTML, native QA, usage review and publication remain pending.
