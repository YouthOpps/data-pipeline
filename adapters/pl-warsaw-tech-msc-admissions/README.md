# Warsaw University of Technology international MSc admissions

This source indexes the [official February intake calendar](https://www.students.pw.edu.pl/index.php/How-to-Apply/Admission-to-M.Sc) from the International Students Office. It emits one opportunity for the intake instead of duplicating the timeline across degree programmes. A related bachelor's degree is required. Programme-specific procedures apply. The adapter never follows the recruitment-system link or submits application material.

It reads the opening, new-application cutoff, qualified-candidate paperwork cutoff and class start as distinct dates. The initial application cutoff determines expiry. A date stays current through that calendar day in Poland. The opportunity ID uses the February cohort year and is stable within that cohort. The source leaves the eligible-country list and funding fields unspecified where no exhaustive factual evidence exists. It uses a brief independent summary and points to the original official source.
