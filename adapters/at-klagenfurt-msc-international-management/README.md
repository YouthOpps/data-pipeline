# University of Klagenfurt MSc International Management

This adapter indexes the public special-admission registration dates for the English-language MSc International Management. It extracts the university’s general window and its separately published earlier window for non-EU/EEA applicants, verifies that the two visible calendar presentations agree, and links directly to the official programme page. The summaries point applicants to the university for eligibility, application requirements and local closing times. These records cover registration for the special admission procedure. The university provides enrollment separately. The early group has a date-only cutoff in Europe/Vienna. The general listing reproduces the university’s published clock label. When that label differs from the offset in effect in Vienna, the date-only record remains until both plausible ends of the published date have passed.

The adapter checks the publisher’s current robots policy before collecting the single canonical programme URL. It honors applicable indexing directives, robots rules and pacing adjustments, and stops on unexpected response status, incomplete framing, publisher challenge, unexpected redirects or unverified journal state. The GitHub Actions workflow owns its durable state per source and preserves the previous publication on failed refreshes. Publisher HTML is used for verification and is excluded from the index.

The hosted nonpublishing test invokes `python -B adapters/at-klagenfurt-msc-international-management/test_adapter.py` under exact branch and run authority. The production workflow additionally requires its separately reviewed first-run state and the scoped data-source credential. Integration tracking is in [issue #442](https://github.com/YouthOpps/data-pipeline/issues/442).
