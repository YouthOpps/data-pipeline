# Aristotle University of Thessaloniki MSEn admissions

This standalone adapter indexes the International Integrated Master's Programme
in Materials Science and Engineering from its official [admissions page](https://msen.auth.gr/admissions).
It reads only that public page and [robots.txt](https://msen.auth.gr/robots.txt).
The first scoped research in issue #429 received two complete HTTP 200
responses. Both crawler groups admitted the exact public page. The received
admissions page did not contain an applicable collection restriction. Terms
for other Aristotle University domains do not govern this reviewed scope.
The adapter does not visit or submit forms, follow redirects, collect
candidate data or reproduce publisher descriptions.

The source inventories the single complete public September intake. Its ID
contains the programme and year, and the reported status comes from an explicit
current intake label. The current researched intake announces 40 places and
rolling admission for September 2027. It gives no applicable fixed applicant
deadline. The adapter does not substitute a deposit date, a programme start
date, an inferred expiry or a country eligibility claim. Missing or ambiguous
intake facts stop collection. An explicit, current-cohort closed label suppresses that validated intake.
Future confirmed cohorts replace the complete
previous publication. Date-only expiry checks use the last possible civil day
for an undated time zone.

inventory. No verified change sequence permits a partial refresh. Both

retains stronger restrictions, cooldown, strikes and pending outcomes. Ordinary

authenticates the separately reviewed hosted QA owner, its immutable source
and exact state archive through the signed artifact transfer. The reviewed

start observation. The eight distinct retained reserve, pre-opener and

collection keeps the last successful dataset and records failure metadata if
