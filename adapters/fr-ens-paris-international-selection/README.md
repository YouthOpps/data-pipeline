# ENS Paris International Selection

Collects the official application windows of the 2027 Arts and Humanities and Sciences admission tracks. The [official French selection page](https://www.ens.psl.eu/une-formation-d-exception/admission-concours/international/concours-selection-internationale) is authoritative for this scope. Both summaries must agree with both detailed application calendars. A foreign-language date conflict cannot override that evidence. Track IDs are separate, deadlines carry their exact Paris time, and geography means hosting rather than eligibility. Funding amounts and candidate requirements remain outside this date-only evidence.

The [hosted research receipt](https://github.com/YouthOpps/ai-workspace/actions/runs/44511911771) retained derived dates and durable access state. It did not retain any page body. The [publisher legal notice](https://www.ens.psl.eu/mentions-legales) requires permission to copy material. This draft uses original summary text and factual dates, honors indexing directives and retains no raw publisher material.

The exact native GitHub Actions branch runs `test_adapter.py` without a publication token, after the settled research workflow is retired. It processes the French page and checks the actual website consumer in memory. The separate `adapter.py --publish` production owner requires independently accepted latest native state and a separately bound maintainer decision before its first run.
