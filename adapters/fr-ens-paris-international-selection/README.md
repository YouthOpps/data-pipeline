# ENS Paris International Selection

Local factual parser draft for the 2027 Arts and Humanities and Sciences admission tracks. The [official French selection page](https://www.ens.psl.eu/une-formation-d-exception/admission-concours/international/concours-selection-internationale) is authoritative for this scope. Both summaries must agree with both detailed application calendars. A foreign-language date conflict cannot override that evidence. Track IDs are separate, deadlines carry their exact Paris time, and geography means hosting rather than eligibility. Funding amounts and candidate requirements remain outside this date-only evidence.

The [hosted research receipt](https://github.com/YouthOpps/ai-workspace/actions/runs/44511911771) retained derived dates and durable access state. It did not retain any page body. The [publisher legal notice](https://www.ens.psl.eu/mentions-legales) requires permission to copy material. This draft uses original summary text and factual dates, honors indexing directives and has no collection or publication entry point.

Hosted native verification is pending. It requires explicit transfer from the latest exact retired research workflow and a memory-only original response and website consumer verification. There is no production workflow in this draft.
