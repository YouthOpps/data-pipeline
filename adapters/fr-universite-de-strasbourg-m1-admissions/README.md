# Université de Strasbourg first-year master’s admissions

This adapter indexes the Faculty of Mathematics and Computer Science’s official first-year master’s admissions for Mathematics and Applications, Actuarial Science and Computer Science. It uses the faculty’s public admissions page, which identifies the three official academic mentions and the Mon Master procedure. The reader follows the official faculty link to check which application route applies. [Official admissions and calendar](https://mathinfo.unistra.fr/en/admissions/admissions/)

The source is restricted to those three master’s mentions in the academic intake shown in the faculty’s calendar. Bachelor’s, second-year master’s, continuing-education and unconfirmed external listings are outside the scope. Record IDs include the native faculty-linked programme identifier and the intake start year. The site’s general application instructions include situation-specific procedures, so the records leave nationality eligibility unspecified.

The 2027–28 text supplies a committee date for Études en France and a separate Mon Master calendar link. It supplies no candidate deadline for these records. The adapter leaves the deadline unset and the opening status unknown. It does not infer expiry from a committee date or the age of a record. A candidate-facing date validated within a later source scope is retained through the end of the stated calendar date when the publication supplies no timezone.

The first hosted research run obtained complete HTTP 200 responses from the exact robots and admissions URLs. The assessed robots rules permitted the requested admissions path and the page declares `index,follow`. The separate legal-notice run continued from that publisher state and obtained a complete notice with fresh robots permission for the notice route. The notice prohibits unauthorized reproduction or public reuse of “la totalité ou d'une partie qualitativement ou quantitativement substantielle du contenu du site”. The catalogue uses only the three programme identities, the intake and original short summaries with a link to the official admissions page. It does not reproduce the site's descriptions, forms, tables or images. Collection opens only the exact robots and admissions URLs and does not follow application platforms, links, PDFs or redirects. The collection reads the entire single admissions page at each refresh. The publisher provides no verified delta or change signal for the three records. The source starts with the reviewed publisher state and preserves its restrictive floors, durable attempts, denials and embargoes. Every request reserves its ownership durably before opening and closes before settlement. The physical gap is at least 12.2 seconds after completion and the rolling limit is five starts per minute. There are no inventory continuations. A durable 429 doubles the current physical and page intervals and retains the required embargo before reading the body. This bounded scope follows no redirects and stops on an unresolved transport failure. Native QA and production use one publisher owner at a time.

The production workflow has one daily run at 07:21 UTC. After validation it atomically replaces this source’s `data.json` and `metadata.json`. Validated expired records leave the source snapshot on success. A fetch or validation error preserves the last-good data and success time. The workflow starts publication after an authorized main merge. Run the sole nonpublishing collection test through the reviewed isolated GitHub Actions workflow with `python -B adapters/fr-universite-de-strasbourg-m1-admissions/test_adapter.py`.
